# Курсы обмена валют

Учебный проект на Python с графическим интерфейсом Tkinter.

## Что делает программа

- Позволяет выбрать **две базовые валюты** и **одну целевую валюту**.
- Получает данные с открытого API **в формате JSON**.
- Показывает сразу два курса, например `1 EUR = ... RUB` и `1 USD = ... RUB`.
- Сообщает об ошибке при отсутствии интернета или недоступности сервиса.

## Запуск

1. Установить Python 3 (Tkinter входит в стандартную поставку Python для Windows).
2. Открыть папку проекта.
3. Запустить файл `main.py` через IDLE: правый клик по файлу → Edit with IDLE → Run → Run Module (F5).
   Альтернатива: выполнить в терминале `python main.py`.
4. Выбрать валюты и нажать **«Получить курс обмена»**.

Для работы нужен доступ к интернету. Дополнительные библиотеки устанавливать не требуется.

## Источник данных

[ExchangeRate-API (Open Access)](https://www.exchangerate-api.com/docs/free) — бесплатные справочные курсы валют с ежедневным обновлением (использование API требует указания источника). Программа получает JSON с адресов вида `https://open.er-api.com/v6/latest/EUR`.
